# Ledger of per-species attribute fall-throughs — generated, then reviewed by hand.
#
# Every line is a (body kind, attribute, species) that has NO explicit value in
# `common/src/comp/body/mod.rs` and is quietly inheriting a catch-all arm. Each line
# is technical debt, not an endorsement: it is here so the debt is countable, and so
# that a *newly added* species that forgets a value fails
# `cargo test -p xindeler-common` instead of shipping silently wrong.
#
# Maintained by `attr_audit_test.rs`. When the test fails it prints the exact `+`/`-`
# lines to add or delete; `ATTR_LEDGER_BLESS=1 cargo test -p xindeler-common --lib
# attr_audit` regenerates this file wholesale.
#
# Adding a species: give it an explicit arm. Only let a line appear here if the
# catch-all genuinely is the right value for it.
# Fixing a species: give it an explicit arm; the line disappears on the next bless.
#
# SCOPE: this covers the getters in `AUDITED` minus those in `DEFAULTS_BY_DESIGN`
# (attributes whose catch-all is the neutral value, not a guess). It is not a
# complete inventory of every default in the engine — see the module docs.
#
# Everything that used to be in here for a *creature* is gone: `mass`,
# `base_health`, `base_poise` and `base_energy` are now required fields in
# `assets/common/body_stats.ron` (a missing species fails the load, by name),
# and `threat_tier`/`magic_resist_tier` are exhaustive matches (a missing
# species fails the build). What is left is `Body::Object` — props,
# projectiles and turrets, which have no species roster to make required.
